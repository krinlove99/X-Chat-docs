## BASETEC AI矩阵

X-Chat是BASETEC旗下基于人工智能大语言模型的聊天助手应用。同时基于AI服务，为具有商用需求的企业组织、开发者及一定规模的用户提供相应的API服务及建站和商业化支持。

目前，BASETEC拥有多种AGC服务：AI聊天、AI搜索、API开放平台、AI翻译、AI音频/图像/视频创作等服务。

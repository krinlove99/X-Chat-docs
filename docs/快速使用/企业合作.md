# 合作

BASETEC于2024年8月1日起推出《企业AGC出海计划》服务支持，帮助企业/组织/用户搭建自己的AI全服务平台，包括人工智能大模型聊天、专业AGC图片音频视频创作等服务。

我们为有合作意向的用户、组织、企业提供定制化版本，你可以独立开展贵组织业务而无需经过BASETEC的应用。

详情请咨询 `business@basetec.top` 。

## X-Chat AI聊天 定制化合作

X-Chat V2 和 V3 版本均提供弱品牌标识版本，即：

- 不含BASETEC品牌标识

- 自定义更换你的品牌标识

- 自定义界面样式

具体内容介绍请查看对应章节

::: tip 如何选择？


- X-Chat V2 适合有二次分发（售卖）需求的用户/组织，采用令牌发卡制，即通过为用户售卖卡密来使用AI聊天服务，并提供API后台进行审计及管理。

- X-Chat V3 可以接入贵组织的客户体系中，采用账户余额制。提供负载均衡、API分发、团队组织及客户管理、预算决策、路由管理、用量审计等更专业的功能。
:::

## AI实验室 定制化合作

AI实验室的所有功能均可以单独选择，并且可以定制化界面与费用规则等，由贵组织独立运营，与BASETEC没有联系。

## AI搜索 定制化合作

提供定制化UI及品牌标识，由贵组织独立运营该搜索引擎，与BASETEC没有联系。

# X-Chat AI聊天助手

## 使用方式

前往BASETEC官网，在导航栏中进入 `AI实验室` ，在功能区选择 `AI对话` 。

或点击前往 [X-Chat：https://basetec.top/ailab/ai-chat](https://basetec.top/ailab/ai-chat)。


![X-Chat](/source/xchat.png)


::: warning 注意
即时用户已经登录了BASETEC官网，在新设备/新浏览器第一次使用AI聊天时仍需再次登录您的BASETEC账户；
:::

该页面中同时提供账户额度管理操作，详见页面右上角的 `管理/功能` ，同时提供基础模型状态展示功能：绿色代表正常，黄色代表繁忙，红色代表异常无法使用。该状态显示具有一定的延迟，并不代表当前时刻的模型状态。如需查看完整的状态，请点击 `查看完整状态` 。如下图所示。


![X-Chat账户管理](/source/xchatmanager.png)

::: warning 注意
如在使用过程中出现未知错误或有其他疑问，请点击 `遇到故障？发起工单` ，并将您在使用哪项服务及遇到的问题填写工单并发送，我们将尽快为您解决。工单处理结果及历史请在官网 个人中心-服务发起查询 中查看。
:::

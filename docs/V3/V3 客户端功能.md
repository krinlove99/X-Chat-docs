# 客户端介绍

## 特性

- 内置 <strong style="color: #007BFF; font-size:12px;font-weight: bold; background-color: #f0f8ff; border: 1px solid #add8e6; padding: 2px 5px; border-radius: 3px;"> Arcnix AI实验室 <sup style="font-size: 0.8em;">&copy;</sup></strong> `X-搜索` 同款AI搜索引擎，AI生成+搜索，没有广告，直达结果
- 大模型“记忆”：支持添加自己近期的动态，如正在学习金融/正在学习《易经》等，全站所有大模型将记住您的个人身份
- 支持与OpenAI相同的语音通话功能，实时对话交流
- 多达几十种个性化语音助手模型
- 支持多模型对话对比
- **支持聊天记录随账号漫游，切换设备自动同步** 
- 支持导入导出、归档及删除等多种对话管理功能
- 支持更多的界面个性化设置，如修改界面风格、修改头像、上传自定义聊天背景图片等

## 聊天记录同步及备份

支持云同步，即在任何设备登录Arcnix账号后，都可以自动同步聊天记录，包括聊天记录、模型调校、使用习惯、文档资料等。同时也支持聊天记录的本地备份，用户可以在设置中开启或关闭聊天记录的本地备份功能。

## 语音识别及生成服务

内置了识别用户语音的功能，通过点击右下角进行语音识别输入，以及支持将对话文本转换为语音，可以在对话回复下的菜单栏中使用。使用这些功能时均不会进行计费。如果您有更专业的语音生成需求，请在前往AI实验室-语音创作服务进行使用。


## 图片生成服务

内置了为所有模型提供免费的图片生成功能，调用时不会进行计费，只需要在对话下的菜单中点击图片生成按钮即可根据对话内容生成图片。如果您有更专业的图片生成需求，请前往AI实验室-图片创作服务进行使用。

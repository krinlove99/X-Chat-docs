# 特色功能

## Flux图片创作

该功能调用 `Flux图片创作模型` + `专业提示词模型` 来生成高质量的图片，用户可以使用自然语言描述，极大降低了高质量图片生成的难度。

Flux图片创作由 Arcnix AI 提供支持。

:::tip 说明
该功能仅为简化版，但由于调用专业图片模型，所以质量依然比其他大模型自带的图片生成更高。

如果您想使用更专业的进阶参数配置，请前往 Arcnix AI实验室 ：https://arcnix.com/ailab 并使用相应的图片生成模型。
:::


### 使用方法

1. 选择模型：`[绘画]Flux专业画师`。

![1](/source/V3/feature1.png)


2. 输入提示词并发送。模型将根据用户输入的提示词先生成一段更专业的提示词，然后输出图片。

![2](/source/V3/feature1-1.png)

![3](/source/V3/feature1-2.png)

## 汉语新解

该功能通过底座大语言模型+代码生成器+代码解释器来生成一副具有一定风格特色的词语解释的SVG卡片。


### 使用方法

选择模型：`汉语新解`

直接输入想要解释的词语，等待回复。

## PPT生成助手

该功能通过GLM-4底座大语言模型+智谱清言智能体来生成PPT文件，并可自行修改样式和纲要内容。


### 使用方法

选择模型：`PPT生成助手`

第1步：输入网址或主题

第2步：确认大纲可用，回复“生成PPT” 

第3步：点击下载or点击预览 点击预览可以修改大纲、自动填充内容、更有多种模板可选

若您想看使用示例 请直接在底部对话框中发送“图片示例”

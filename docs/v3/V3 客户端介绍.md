# V3 客户端介绍

## 新特性
- 继承 V2 版本所有的功能
- 新的UI界面，更流程的使用体验

![1](https://raw.gitmirror.com/krinlove99/pic/main/basetec/oichat.png)

- 工作空间：开放用户自定义模型、提示词的功能，基于X-Chat提供的模型之上，用户可以自行上传文档作为大模型知识库，打造用户专属模型。

![2](https://raw.gitmirror.com/krinlove99/pic/main/basetec/modeldiy.jpg)

- 内置BASETEC X-搜索同款AI搜索引擎，AI生成+搜索，没有广告，直达结果

![3](https://raw.gitmirror.com/krinlove99/pic/main/basetec/searxng.png)


- 大模型“记忆”：支持添加自己近期的动态，如正在学习金融/正在学习《易经》等，全站所有大模型将记住您的个人身份
- 支持与OpenAI相同的语音通话功能，实时对话交流
- 多达几十种个性化语音助手模型，详见X-Chat使用文档的《语音模型声线列表》介绍
- 支持多模型对话对比

![4](https://raw.gitmirror.com/krinlove99/pic/main/basetec/e7427d560v15a8bf4522f90a99d5093a.jpg)

- 支持聊天记录随账号漫游，切换设备自动同步
- 支持隐私模式，本地浏览器及云端都将不保存您的对话信息
- 支持导入导出、归档及删除等多种对话管理功能
- 支持更多的界面个性化设置，如上传自定义背景图片等

![5](https://raw.gitmirror.com/krinlove99/pic/main/basetec/xchat.jpg)

## 聊天记录同步及备份

X-Chat V3 版本支持云同步，即在任何设备登录BASETEC账号后，都可以自动同步聊天记录，包括聊天记录、模型调校、使用习惯、文档资料等。同时，X-Chat V3 版本也支持聊天记录的本地备份，用户可以在设置中开启或关闭聊天记录的本地备份功能。

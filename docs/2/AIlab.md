# AI实验室

AI实验室是为BASETEC用户提供的最先进的AI衍生服务，如AI视频创作、图片创作、AI语音生成、音色克隆、照片修复等内容。AI实验室绑定BASETEC用户体系，采用账户余额制。


## Stable Diffusion AI生图服务

::: tip Stable Diffusion
Stable Diffusion 是一种基于深度学习的图像生成模型。与其他生成模型相比，Stable Diffusion 能够生成更高质量、更细节丰富的图像，同时可以用于各种图像生成任务，如图像修复、图像超分辨率、图像生成等。
:::

### 使用方式

前往BASETEC官网并登录，进入个人中心，在功能区中选择 `AI实验室` 。

该功能与大语言模型生图的区别：支持更专业的参数调校、更可控的风格和效果以及更低的资费，并且可以永久存储。

您生成的图像将为您持续保存，您可以在个人中心查看、下载、分享您的图像。

### 资费
目前该功能处于公测阶段，暂不收费。

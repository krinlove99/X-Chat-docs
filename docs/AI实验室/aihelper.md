# AI智能语音助手-iOS端

::: tip 最新版本 `V1.1`

2024年8月30日更新

更新内容：

- 首个AI智能语音助手版本发布
:::

AI智能语音助手搭载 `BASETEC AI` ，可在iOS平台上通过 `嘿 Siri` 的原生调用方式来使用人工智能助手。

AI智能语音助手可以与用户进行对话，帮助用户解决日常生活中的疑问，总结分析剪贴板的文档/网页链接，进行图像AI识别分析等。并可进一步选择将对话内容保存至备忘录或本地文件。

## 使用方式

### 下载

1. 前往[BASETEC官网-客户增值服务：https://basetec.top/openSource](https://basetec.top/openSource)

2. 选择并进入 `AI智能语音助手` 项目

3. 根据提示进行下载

4. 在App Store中安装Apple官方应用 `快捷指令`

::: tip 注意
AI智能语音助手目前只支持Apple设备进行使用，具体支持设备如下：

- 安装了快捷指令的iPhone、iPad
- 支持快捷指令的Macbook系列、Mac Studio系列、Mac Mini系列
- 支持快捷指令的Apple Watch系列
:::

### 配置

1. 复制获得的下载链接并在浏览器中打开（不要使用微信自带浏览器）

2. 点击 `获取捷径` 

3. 如果你已经安装快捷指令应用，将会跳转到该App，点击 `添加快捷指令` 按钮完成安装

4. 完成安装，无需额外配置即可通过 `嘿，Siri，助手！` 来使用，或将其 `保存到主屏幕` 使用


### 使用

1. 服务已内置BASETEC AI官方模型 `gpt-4o-mini` ，提供快速的响应，完全免费，无需配置即可使用。

::: warning 注意
默认模型不支持图像识别，如需使用图像识别或使用其他模型，请参考下方教程。

❗️如无专业知识，请勿擅自修改。
:::

2. 自定义模型及使用图像识别功能

进入 `快捷指令` 应用中的 `助手(本指令)` 指令内部，下划至

`┏┅┅┅┅┅┅配置项开始┅┅┅┅┅┅┓` 处，

更换API_KEY文本框内为自己的API_KEY（ `sk-` 开头），并酌情修改相应的模型名称和BaseUrl。

BaseUrl请更换为与API平台相关的地址。

其他内容参考指令内的注释。
